The Domain Name System (DNS) is fundamental to Internet infrastructure, and its stability is essential for ensuring reliable network access. While prior work has focused on coarse-grained failure statistics, in-depth analysis of specific failure types and their causes remains limited. In this study, we present a DNS failure analysis framework that combines coarse- and fine-grained perspectives over time. Using a real-world dataset of 2.5 billion DNS records, we systematically identify and classify major DNS failure patterns and quantify the distribution characteristics of each failure type, providing valuable insights into the underlying causes of DNS failures.
